# shopping-cart-app

A Vite and React online shopping cart application for the 2026-09-22 assignment.

## Features

- Welcome home page with a product catalog
- Reusable `Header`, `ProductList`, `ProductCard`, `Cart`, and `Footer` components
- Add products to the cart with a temporary success notification
- Increase or decrease quantities
- Remove individual products or clear the whole cart
- Live cart item count and total price
- Responsive layout for desktop and mobile screens

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser. To create a production build:

```bash
npm run build
```
