# Student Attendance Management System

A responsive React dashboard for recording college class attendance and monitoring student eligibility.

## Run locally

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Create a production build with `npm run build`.

## Attendance behavior

The roster starts with the requested sample students and attendance percentages. Marking Present or Absent records one class for that student and updates their percentage and the live summary. Changing a mark corrects the current session without adding another class. Reset restores the original sample data.
